# Template de avaliação de iniciativa

Copie este bloco para cada item de backlog.

```
INICIATIVA: ____________________________________________

Origem da demanda:        [ Vendas | Cliente atual | CS/Suporte | Security/CRA | Discovery | Engenharia/Produto | Pipeline ]
Problema a resolver:      ____________________________________________
Hipótese de valor:        Acreditamos que [solução] vai gerar [resultado/OKR] para [quem]
Evidências disponíveis:   (fontes e o que cada uma diz)
                          - ____________________________________________
                          - ____________________________________________

NOTAS DE IMPACTO (1–5)
  D1 ARR ..................... [ ]
  D2 Abrangência ............. [ ]
  D3 CRA / Estratégico ....... [ ]

  Impacto bruto = (D1+D2+D3) ÷ 3 = ______

PONDERADORES
  Confiança:  [ Baixa 0,70 | Média 0,85 | Alta 1,00 ]   →  fator = ______
  HIPO:       [ Despriorizar 0,85 | Neutro 1,00 | Priorizar 1,15 ]   →  fator = ______
              (se ≠ Neutro, registrar:  quem decidiu ______  por quê ______ )

  Impacto final = bruto × fator confiança × fator HIPO = ______   (máx 5,00)
  Classificação: [ Baixo | Médio | Alto ]

TRAVA DE ALAVANCAGEM:      D2 é 1–2 e classificou como Alto?  [ Não ]
                          Se Sim → exceção válida? (CRA / segurança crítica / ARR material)
                          Exceção registrada por: __________  Justificativa: __________

ESFORÇO:                   [ Baixo | Médio | Alto ]
QUADRANTE DA MATRIZ:       ____________________________________________

DECISÃO RECOMENDADA:       [ Fazer agora | Planejar (PI) | Avaliar trade-off | Backlog | Customização (serviço/parametrizar) | Recusar ]
PRÓXIMOS PASSOS / DONO:    ____________________________________________
```

## Output agregado da sessão

- Matriz/planilha preenchida (Impacto × Esforço).
- Tabela de decisões: item → quadrante → decisão → dono → próximo passo.
- Lista de exceções da trava registradas (dono, justificativa, OKR/risco).
- Lista de HIPOs ≠ Neutro registrados (quem decidiu, por quê).
