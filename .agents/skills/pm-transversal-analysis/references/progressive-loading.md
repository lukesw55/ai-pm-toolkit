# PM transversal analysis progressive loading map

Use `SKILL.md` as the control plane.

| File | Purpose | Load when |
|---|---|---|
| `references/qualitative-synthesis.md` | Two-pass coding (open → axial → thematic) of interviews, tickets, and survey free-text into themes with evidence | Coding or synthesising qualitative data |
| `references/quantitative-analysis.md` | Funnel, retention, cohort, and segment interpretation workflow with data-quality checks | Interpreting behavioural data or structuring a quant query |
| `references/triangulation.md` | Protocol for cross-referencing qualitative themes with quantitative signals, including conflict handling | Combining or reconciling quali and quant evidence on a claim |
| `references/media-transcript-parsing.md` | Handling videos, audio, transcripts, and session replays: transcript-first processing with timestamped excerpts | The main input is a recording, transcript, or session replay |
| `references/batch-interview-synthesis.md` | Five to ten transcripts: shared codebook, one excerpt log per transcript, fan-out with a sequential fallback, merge by participants | Synthesising a round of interviews with several transcripts |
| `references/connector-task-recipes.md` | Recipes for closing a PM task through Jira and analytics MCP connectors with source links, persistence and TBD rules | A routine question a connector can answer end to end |
| `references/progressive-loading.md` | Loading map | Choosing the narrowest reference |
