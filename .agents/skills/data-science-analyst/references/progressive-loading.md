# Data Science Analyst progressive loading map

Use `SKILL.md` for routing and guardrails.

| File | Purpose | Load when |
|---|---|---|
| `references/playbook.md` | Mode-specific data workflows | You need detailed steps for EDA, SQL, experiments, ML, or reporting |
| `references/report-templates.md` | Output templates | The user asks for a report, model card, or executive summary |
| `references/progressive-loading.md` | Loading map and validation shortcuts | You need the smallest safe analysis path |
| `references/python-patterns.md` | Python analysis patterns | Implementing a Python analysis |
| `references/sql-patterns.md` | SQL analysis patterns | Writing analytical SQL |
| `references/posthog-mcp-patterns.md` | PostHog tool patterns | Querying PostHog through MCP |
| `scripts/profile_dataset.py` | Dataset profiling CLI | Checking a new dataset |
| `scripts/scaffold_analysis_project.py` | Analysis project scaffold | Starting a reproducible analysis |
