# PM transversal docs progressive loading map

Use `SKILL.md` as the control plane.

| File | Purpose | Load when |
|---|---|---|
| `references/confluence-structure.md` | Space architecture, page anatomy, and cross-page linking conventions | Designing a space, page structure, or linking convention |
| `references/confluence-templates.md` | Ready-to-paste templates: PRD, strategy memo, DACI, launch plan, release notes, retro, FAQ | Producing a specific Confluence artefact |
| `references/jira-ticket-hygiene.md` | Ticket anatomy per type, fields that matter, Definition of Ready checklist | Writing or restructuring Jira tickets and epics |
| `references/jira-linking-automation.md` | Cross-ticket link types, parent/child hierarchy, automation recipes, Confluence-Jira bidirectional links | Designing the linking map or backlog automations |
| `references/progressive-loading.md` | Loading map | Choosing the narrowest reference |
