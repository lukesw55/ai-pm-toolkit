# Inference discipline progressive loading map

Use `SKILL.md` for the shared evidence, uncertainty, and authorization contract. Apply its rules when relevant; do not reread the full skill or load an example for a routine, settled choice.

| File | Purpose | Load when |
|---|---|---|
| `references/approval-examples.md` | Ambiguous-scope, reversible-edit, memory, and authorization examples | A material ambiguity blocks action, memory may be stale, or an authorization boundary is unclear |
| `references/progressive-loading.md` | This loading map | You need to choose supporting guidance or check the hook boundary |

The skill is guidance, not a permission system. Hooks enforce only their configured routes and literal checks. Verify facts with their sources; do not treat a clean hook result as proof.
