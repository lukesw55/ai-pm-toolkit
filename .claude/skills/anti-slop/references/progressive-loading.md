# Anti-slop progressive loading map

Use `SKILL.md` as the gate control plane.

| File | Purpose | Load when |
|---|---|---|
| `references/code-catalogue.md` | Code, comments, and repo-structure anti-patterns | Reviewing generated code or a source diff |
| `references/doc-catalogue.md` | Markdown, README, PR, ADR, and product-doc anti-patterns | Reviewing docs or long-form repository text |
| `references/reply-catalogue.md` | Chat/reply anti-patterns | Reviewing the assistant's final answer before sending |
| `references/test-catalogue.md` | Test and fixture anti-patterns | Reviewing tests or generated fixtures |
| `references/progressive-loading.md` | Loading map and routing notes | Choosing the narrowest anti-slop pass |
