# PM Phase — Deliver progressive loading map

Use `SKILL.md` as the control plane.

| File | Purpose | Load when |
|---|---|---|
| `references/experiment-interpretation.md` | Experiment design and A/B interpretation: hypotheses, primary metrics, guardrails, validity, decision rules | Interpreting an A/B result or deciding whether A/B fits at all |
| `references/launch-readiness.md` | GTM coordination, launch stages (dark launch → GA), enablement, go/no-go | Preparing a launch or verifying readiness before the gate opens |
| `references/metric-quality-guardrails.md` | Metric trustworthiness: definition drift, measurement bias, novelty effects, guardrail design | Checking whether a measured change is real, meaningful, and safe to ship |
| `references/post-launch-monitoring.md` | The learning window, actuals vs hypothesis, iterate/scale/hold/rollback/stop | Monitoring a shipped feature or writing the close-out memo |
| `references/product-analytics.md` | Funnels, retention, cohorts, segmentation turned into decisions | Interpreting behavioural data or building an analytics narrative |
| `references/release-notes.md` | Audience-fit release comms: public changelog, internal enablement, customer notices, migration FAQ | Drafting release notes or customer/internal comms |
| `references/progressive-loading.md` | Loading map | Choosing the narrowest reference |
