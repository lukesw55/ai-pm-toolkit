# Régua Comum progressive loading map

Use `SKILL.md` as the control plane.

| File | Purpose | Load when |
|---|---|---|
| `references/examples.md` | Three worked examples across quadrants, weighters and lock in action | Calibrating scores or settling a disputed rating |
| `references/rubric.md` | Verbatim 1–5 rubrics for the three impact dimensions and the six effort signals | Scoring impact dimensions or rating effort |
| `references/templates.md` | Fill-in evaluation block, one per backlog item | Scoring a concrete initiative |
| `references/workshop.md` | 60–90 min workshop agenda and governance rules | Preparing or facilitating a prioritization session |
| `references/progressive-loading.md` | Loading map | Choosing the narrowest reference |
