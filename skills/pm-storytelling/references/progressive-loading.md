# PM storytelling progressive loading map

Use `SKILL.md` for mode detection, narrative spine, and output contract.

| File | Purpose | Load when |
|---|---|---|
| `frameworks/STORY_FRAMEWORKS.md` | 13 narrative frameworks and a selection heuristic | Phase 3, when the default framework table in `SKILL.md` is not enough to choose |
| `templates/OUTPUT_TEMPLATES.md` | Fillable templates per format | Phase 5, once the format is chosen |
| `references/format-editorial-rules.md` | Format-specific editorial rules | User asks for a memo, article, script, case study, or presentation-ready narrative |
| `references/deck-storyline.md` | Per-slide assertion-evidence contract, QBR slide budget, optional render handoff | Deliverable is a deck: QBR, exec review, stage-7 kickoff, pitch |
| `rubrics/QUALITY_RUBRIC.md` | 1–5 scorecard plus the binary outbound voice gate | Phase 7, before the final response |
| `references/progressive-loading.md` | Loading map and routing notes | Source material is large or crosses PM/story/humanizer boundaries |
