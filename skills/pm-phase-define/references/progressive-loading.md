# PM Phase Define progressive loading map

Use `SKILL.md` as the control plane.

| File | Purpose | Load when |
|---|---|---|
| `references/strategy-memo.md` | Strategy memo structure: pillars, bets, explicit non-goals | Formulating direction or writing a strategy memo |
| `references/kpi-tree.md` | North Star and metric-tree design with guardrails | Building or auditing a KPI architecture |
| `references/opportunity-sizing.md` | Top-down plus bottoms-up sizing with sensitivity analysis | Sizing an opportunity or stress-testing a demand model |
| `references/one-pager.md` | Stage-4 One Pager template bridging discovery to prioritisation | Synthesising a validated problem into a build candidate |
| `references/business-case-prfaq.md` | Investment memo and PRFAQ templates with return logic | Justifying a material bet or working backwards from a press release |
| `references/pricing-packaging.md` | Value metrics, tiers, packaging, and migration policy | Working on pricing or packaging decisions |
| `references/prioritisation-frameworks.md` | Framework selection (RICE, WSJF, Kano, MoSCoW) and scoring rubrics | Ranking initiatives or choosing a prioritisation method |
| `references/roadmap-narrative.md` | Roadmap types, narrative structure, commitment gradient | Building or defending a roadmap |
| `references/decision-memo-daci.md` | Decision memo, DACI, and ADR forms with templates | Documenting a decision or clarifying decision rights |
| `references/progressive-loading.md` | Loading map | Choosing the narrowest reference |
